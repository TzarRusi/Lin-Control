# Протокол LIN Control

USB CDC работает на 115200 бод. Каждая команда завершается переводом строки. LIN UART поддерживает 9600, 10400 и 19200 бод; основной стенд работал на 19200.

## Базовые команды

| Команда | Назначение |
|---|---|
| `PING` | проверка связи с прошивкой |
| `INFO` | версия, частоты, BRR, выводы и состояние |
| `ENABLE 0/1` | выключить/включить TJA1021 через SLP_N |
| `BAUD 9600/10400/19200` | выбрать скорость LIN |
| `ECHO` | проверить UART loopback через трансивер |
| `WAKE` | отправить LIN wake-up pulse |
| `POLL hh` | отправить Break/Sync/PID и принять ответ ведомого |
| `FRAME id hex` | отправить master frame с payload |
| `STOP` | немедленно отключить LIN и отпустить PS_ON |

## Питание

| Команда | Назначение |
|---|---|
| `POWER 1` | включить запрос PS_ON и запустить lease 3000 мс |
| `POWER KEEP` | продлить уже активный lease |
| `POWER 0` | отпустить PS_ON |
| `POWER?` | вывести логическое состояние и остаток lease |

## LIN frame

Контроллер формирует:

```text
BREAK → 0x55 → protected identifier → payload → checksum
```

Для ID `0x00..0x3B` вычисляются parity bits P0/P1. Для LIN 2.x используется enhanced checksum с PID; диагностические ID `0x3C/0x3D` используют classic checksum.

## Подтверждённые status frames

Ответы имеют 8 байт данных и LIN checksum. Первый байт — внутренний CRC-8-H2F, младшая тетрада второго байта — counter.

| ID | Длина защищённых данных | DataIDList[16] |
|---:|---:|---|
| `14` | 6 | `2E D4 7F 2A D0 7B 26 CC 77 22 C8 73 1E C4 6F 1A` |
| `1E` | 4 | `0F DE B2 86 5A 2E FD D1 A5 79 4D 21 F0 C4 98 6C` |
| `32` | 3 | `03 E8 D2 BC A6 90 7A 64 4E 38 22 0C F1 DB C5 AF` |

Внутренний CRC вычисляется полиномом `0x2F`, init `0xFF`, xorout `0xFF` над защищёнными байтами и DataID, выбранным текущим counter.

## Циклический режим

`CYCLECLR`, `CYCLEADD` и `CYCLERUN` загружают до 32 кадров и исполняют равномерный цикл. В каждом периоде слоты распределяются как:

```text
0A command → 28 command → 14 status → 32 status → 1E status
```

Период одного ID — 100 или 200 мс. Во время цикла MCU самостоятельно проверяет UART, эхо, checksum статусов, тайминги и признак положения; USB используется только для итогового отчёта.
