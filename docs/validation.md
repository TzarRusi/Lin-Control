# Проверки и результаты

Прототип проверен на реальном стенде STM32F103C8 + TJA1021 + автомобильный LIN-узел.

## Подтверждено

- native USB CDC и командный интерфейс;
- LIN Break/Sync/PID на USART2;
- эхо каждого переданного кадра;
- чтение ответов ID `14`, `1E`, `32`;
- classic/enhanced LIN checksum;
- внутренние CRC-8-H2F и rolling counter ответов;
- равномерное циклическое расписание из 50 слотов;
- отсутствие UART errors и capture overflow в штатных циклах;
- `PS_ON` open-drain и аппаратный таймер lease 3 секунды;
- отключение питания по `STOP`, таймауту, потере USB и ошибке транспорта;
- воспроизводимый обмен на 19200 бод.

## Характерные сигнатуры

Правое положение устройства давало стабильные значимые поля:

```text
ID 14: 00 00 78 00 E4 FF 1F
ID 1E: 00 01 FE FF FF FF FF
ID 32: 50 FE FF FF FF FF FF
```

Для автоматического детектора использовалась составная сигнатура: `ID14 data[5] = E2` и старшая тетрада `ID32 data[1] = B`, подтверждаемая тремя последовательными опросами перед остановкой.

## Защитные проверки

- 107 USB-команд без LIN-передачи;
- 17 сценариев PS_ON при отключённых 12 В;
- проверка lease, `POWER KEEP`, `STOP` и разрыва DTR;
- offline fixtures для PID, checksum, CRC и status decoder;
- simulated stable/change/bad_echo/bad_crc outcomes;
- остановка при noise/framing/overrun, неверном эхо и рассинхронизации цикла.

Итоговый прототип обеспечивает устойчивый транспорт LIN и диагностическое чтение состояния с контролируемым питанием стенда.
